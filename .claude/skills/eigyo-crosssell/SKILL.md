# 横展開提案スキル

## 手順
1. `search_customers` で得意先を特定し、`cross_sell` で候補を取る（同業＝同じ業種で購買カテゴリが似ている得意先）。
2. 候補ごとに「どの同業で・どれくらい・いつ売れたか」の根拠を確認する。根拠が 1 社だけの候補は弱いので順位を下げる。
3. 得意先メモ（`search_customers` の notes）と業種に合わせ、商談の切り出し 2〜3 文、候補ごとの一言提案・なぜ今・想定反論を書く。
   - 他社の社名は **出さない**。「同業のお客様」「同じ地域の工場」と言い換える。
4. 価格を聞かれたら `propose_price` で参考単価と粗利を確認してから答える。
5. 提案が採用されたら `eigyo-quote` スキルの手順で見積りを作る。
