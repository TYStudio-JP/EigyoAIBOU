# 見積り作成スキル

営業AI棒の MCP ツール（`eigyo-aibou`）を使って、依頼文から見積り（下書き）を作る。

## 手順
1. `extract_request` に依頼文をそのまま渡し、得意先・明細・納期・不明点を得る。
2. 得意先が曖昧なら `search_customers` で確定する。候補が複数なら **ユーザーに確認**する（勝手に決めない）。
3. 各明細について `search_products` で商品を特定する。見つからない品は「未登録品」として description で扱い、ユーザーに伝える。
4. `propose_price` で得意先×商品×数量の提案単価・値引き下限・チェックを確認する。
   - `danger`（原価割れ）は必ず報告し、そのまま提出しない。
   - `warn`（前回より値下げ／粗利下限割れ／他社より安い）は理由をユーザーに確認し、備考に残す。
   - `cheaper_route` があれば、安い仕入れルートに切り替えるか提案する（納期・最小ロットも併記）。
5. `create_quote` で見積りを作成する。単価を変えたい明細だけ `unit_price` を指定する。
6. 結果を次の形式で報告する：見積番号、合計・粗利率、明細ごとの単価と根拠、警告、得意先に確認すべきこと、Web の URL。

## 報告のトーン
- 営業担当が 30 秒で判断できるよう、警告 → 根拠 → 次の一手 の順で短く。
- 「前回 6,700 円（2026-10-24 Q202610-024）→ 今回 6,500 円（-3%）」のように、数字は比較で示す。
