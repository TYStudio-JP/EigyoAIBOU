# デスクトップ版デモ用ファイル一式

基幹システムから書き出した CSV を取り込み、その実績を使って見積り・価格改定・横展開までを見せるための素材です。
会社名・人名・商品・価格はすべて架空です。メールアドレスは `example.jp` です。

## 入っているもの

| フォルダ | ファイル | 使う画面 | AI |
|---|---|---|---|
| `01_マスタ取り込み` | `1_得意先マスタ.csv` ～ `5_売上実績.csv` | 設定 → マスタ取り込み（CSV） | 不要 |
| `02_見積り依頼` | `メール_三州きらら精機.txt` | 見積りを作る（本文を貼る） | 必要 |
| `02_見積り依頼` | `見積依頼書_房総みなと運輸.xlsx` | 見積りを作る（ファイルを選ぶ） | 必要 |
| `03_電話メモ` | `電話メモ_あずみ野デリカ.txt` | 電話メモ → 新しい電話メモ | 必要 |
| `04_メーカー回答` | `回答メール_ミツワ精測.txt` | 見積りの明細 → メーカー回答を入れる | 無くても可 |
| `05_問い合わせ` | `問い合わせ_短文.txt` | 問い合わせ回答 → 記録 | 無くても可 |
| `06_訪問予定` | `訪問予定.ics` | 訪問予定 → カレンダー取り込み → .ics を貼り付ける | 不要 |
| `07_名刺・写真` | `名刺_岡田様.png` `名刺_宮下様.png` | 得意先 → 担当者を追加（名刺OK） | 必要 |
| `07_名刺・写真` | `商品ラベル_DC-150.png` `商品ラベル_他社品.png` | 写真で調べる | 必要 |
| `08_見積書テンプレート` | `見積書テンプレート_ツヤ商事.xlsx` | 設定 → 見積書の書式 | 不要 |

CSV は基幹システムの書き出しを想定した Shift_JIS です。Excel でそのまま開けます。テキストエディタで文字化けする場合は文字コードを Shift_JIS にしてください。

## 準備

1. データを初期状態に戻します。取り込んだ内容や試した見積りはすべて消えます。

   ```bash
   npm run seed
   ```

2. 起動します。

   ```bash
   npm run dev
   ```

3. 設定 → ユーザー で「山田 太郎」が「操作中」になっていることを確かめます。

## 1. マスタを取り込む（設定 → マスタ取り込み（CSV））

「取り込むもの」を選び、CSV を選んで「読み込む」→ 列の対応を確認 →「取り込む」。**番号順に**取り込んでください（商品や得意先が先に無いと、価格表と売上実績の行が弾かれます）。

| 順 | 取り込むもの | ファイル | 結果 | 見どころ |
|---|---|---|---|---|
| 1 | 得意先マスタ | `1_得意先マスタ.csv` | 7 行中 追加 5・更新 2 | 「得意先CD」「担当者名」などの列名が自動で当たる。「営業担当」で山田／鈴木に割り当て。掛率・粗利率・端数単位が値付けルールになる |
| 2 | 仕入れ先マスタ | `2_仕入先マスタ.csv` | 4 行中 追加 3・更新 1 | 既存の東和切削工具は標準納期だけ 10 → 8 日。空欄の掛率・メールは元のまま |
| 3 | 商品マスタ | `3_商品マスタ.csv` | 15 行中 追加 13・更新 2 | 新しい区分「測定工具」「物流機器」が増える。既存 2 品は規格だけ更新 |
| 4 | 仕入れ価格表 | `4_仕入価格表.csv` | 25 行中 追加 25 | 新商品の仕入れルートと、日新ケミカル 4 品の 11 月値上げ（10%） |
| 5 | 売上・受注実績 | `5_売上実績.csv` | 163 行中 追加 59 | 同じ伝票番号の行が 1 件の受注見積りにまとまる。半年分・5 社 |

取り込み後に確かめる場所：

- **得意先・横展開**：「自分の担当」に三州きらら精機・あずみ野デリカ・房総みなと運輸・甲斐やまなみ電子が増える。上州あかぎ建材は鈴木の担当。
- **案件**：取り込んだ 59 伝票が、得意先ごと・話ごとに 19 件前後の案件にまとまっている（毎月の定期補充は 1 つの案件）。
- **商品・仕入れ**：デジタルノギスなど 13 品と仕入れルート。

## 2. 取り込んだ実績で見積りを作る（見積りを作る）

`メール_三州きらら精機.txt` の中身を貼り付けて「読み取って見積りを作る」。

| 品目 | 提案単価 | 根拠 |
|---|---|---|
| デジタルノギス DC-150 ×5 | 8,800 円 | 9 月の同得意先向け受注単価を踏襲 |
| 外側マイクロメータ MC-25 ×3 | 11,340 円 | 同上 |
| 超硬エンドミル EM-6-2F ×20 | 3,570 円 | 10 月の受注単価を踏襲 |
| 水溶性切削油 CO-18 ×6 | 9,965 円 | 前回は 9,620 円。11 月の仕入れ値上げで粗利下限 15% を割るため、下限価格に引き上げ |
| ピンゲージセット PG-51 ×1 | 19,950 円 | 初回品。最安仕入れ 15,960 円に得意先の掛率 1.25・10 円単位切り捨て |

**見どころ**：「前回と同じ条件で」と書かれていても、切削油だけは仕入れが上がっているので、そのまま出すと粗利割れになることを先に知らせます。

Excel の依頼書でも同じことができます。`見積依頼書_房総みなと運輸.xlsx` をファイルで選んで読み取ると、台車 11,500 円・パレット 4,800 円・ラッシングベルト 2,200 円・ストレッチフィルム 3,700 円は前回単価、初めてのハンドパレットトラックは掛率 1.30・100 円単位で 54,800 円になります。

## 3. メーカー回答を入れる（見積りの明細）

2 で作った見積りを開き、ピンゲージセットの明細で「メーカー回答を入れる」→ `回答メール_ミツワ精測.txt` を貼り付け。単価 15,400 円・納期 11/20・有効期限 12/25・最小ロット 1 が入り、「いつもの掛率で値付け」で売単価が 19,250 円に変わります。

この入力欄はスマホ表示の見積り画面にあります。PC ではブラウザの幅を狭めると出ます。

## 4. 価格改定の影響（価格改定の影響）

取り込み前は 0 行。取り込み後は、日新ケミカルの値上げで粗利下限を割る組み合わせが出ます。

| 得意先 | 商品 | 直近の売単価 | 現在の仕入れ | 粗利 |
|---|---|---|---|---|
| 三州きらら精機 | 水溶性切削油 CO-18 | 9,620 円 | 8,470 円 | 12.0% |
| 三州きらら精機 | 防錆剤スプレー RP-420 | 10,920 円 | 9,610 円 | 12.0% |
| あずみ野デリカ | 工業用洗浄剤 CL-20 | 6,280 円 | 5,390 円 | 14.2% |

**見どころ**：値上げ交渉が必要な先と、守るべき売価がひと目で分かります。

## 5. 横展開（得意先・横展開）

- **東海精密**（既存の得意先）を開くと、提案候補にデジタルノギス・外側マイクロメータ・ダイヤルゲージが出ます。同業の三州きらら精機に売れている実績を取り込んだためです。
- **三州きらら精機**を開くと、同業で売れていて未購入の外径バイトホルダ・極圧グリースなどが出ます。

## 6. 電話メモ（電話メモ → 新しい電話メモ）

得意先に「あずみ野デリカ」を選び、`電話メモ_あずみ野デリカ.txt` を貼って「議事録・回答・確認メールを作る」。作成中は他の画面へ移っても続きます。

- ワイパー 30 箱・ゴミ袋 20 箱は見積り下書きが自動でできる（前回単価 5,600 円・4,230 円）。
- ワイパーの納期は、仕入れルートから最短の入荷日が出る。
- 耐切創手袋 M サイズは前回単価 1,180 円。
- 防塵マスクの「1,700 円に合わせられないか」は、前回 1,840 円・値引き下限 1,694 円と比べた結果が付く。

## 7. 問い合わせ回答（問い合わせ回答 → 記録）

`問い合わせ_短文.txt` の【1】～【3】を 1 件ずつ貼ります。

- 【1】取り込み前は M サイズの記録が無く「メーカー確認」になります。取り込み後は HK-5M が商品マスタに当たります。
- 【2】フルハーネスの最短納期と、規格欄の「ランヤード別売」を材料に回答します。
- 【3】規格欄の「四方差し・動荷重 1t」と仕入れルートの納期を材料に回答します。

## 8. 訪問予定（訪問予定 → カレンダー取り込み → .ics を貼り付ける）

`訪問予定.ics` をメモ帳で開いて全文を貼り、「取り込む」。7 件のうち 6 件が得意先に自動で紐づき、社内会議は紐づきません。

予定の日付は 2026/11/06 ～ 11/13 です。取り込めるのは実行日の 7 日前から 30 日先までなので、撮影日がずれる場合は .ics の `DTSTART` `DTEND` の日付を書き換えてください。

## 9. 名刺・写真

- **名刺**：得意先 →「担当者を追加（名刺OK）」→ `名刺_岡田様.png`。会社名から三州きらら精機に紐づき、部署・役職・携帯・メールが入ります。
- **写真で調べる**：`商品ラベル_DC-150.png` は自社の取扱品に品番で一致。`商品ラベル_他社品.png` は品番では当たらず、同じ測定工具の取扱品が候補に出て、ウェブ検索へ進めます。

## 10. 自社書式の見積書（設定 → 見積書の書式）

`見積書テンプレート_ツヤ商事.xlsx` を選んで「登録」。以後、見積りの Excel 出力がこの書式になります。`{{quote_no}}` などが差し込み位置で、`{{item.*}}` の行が明細の数だけ複製されます。

## やり直すとき

`npm run seed` で初期状態に戻ります。登録した見積書テンプレートは設定画面から削除できます。
